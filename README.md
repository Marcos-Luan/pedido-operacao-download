# PedidosOn Tablet

[Baixar PedidosOn Tablet v26](https://github.com/Marcos-Luan/pedido-operacao-download/raw/refs/heads/main/Pedido_Operacao_Relatorios.apk)

O PedidosOn Tablet v26 instala ao lado do app antigo. No primeiro acesso, um gerente
precisa vincular o tablet ao restaurante. Depois, selecione a impressora Bluetooth
principal na lista do aplicativo.

Se houver pedidos pendentes no app antigo, sincronize-os por lá. A fila offline
fica no aplicativo em que os pedidos foram criados.
