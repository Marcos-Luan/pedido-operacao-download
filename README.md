# Pedido Operação — Android

[Baixar APK](https://github.com/Marcos-Luan/pedido-operacao-download/raw/refs/heads/main/Pedido_Operacao.apk)

Versão piloto: login de atendentes por número 01–12 e senha individual; gerente e cozinha por e-mail e senha. Impressão Bluetooth e Wi-Fi compatível. Requer conta autorizada e configuração do sistema. Antes de substituir versões piloto anteriores, sincronize todos os pedidos pendentes.
